# Peloponéz 2026 – mapa plánu

Interaktívna mapa rodinnej dovolenky po Peloponéze (16.–30. 8. 2026):
kempy, zastávky a trasy po dňoch. Jeden statický HTML súbor, Leaflet + OSM.

**Mapa:** https://msatala.github.io/peloponez-mapa/

Zdrojová verzia plánu je v privátnom repozitári; tento repo obsahuje len mapu,
aby sa dala otvoriť na telefóne bez GitHub účtu. Stránka je `noindex`.
