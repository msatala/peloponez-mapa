# Peloponéz 2026 – mapa plánu

Interaktívna mapa rodinnej dovolenky po Peloponéze (16.–30. 8. 2026):
kempy, zastávky a trasy po dňoch. Statické HTML, Leaflet + OSM.

- **v4 – aktuálna, s overenými kempami:** https://msatala.github.io/peloponez-mapa/v4.html
- v3 – pôvodná verzia: https://msatala.github.io/peloponez-mapa/

Vo v4 sú kempy na 16.–24. 8. overené priamo v rezervačných systémoch kempov
(Lefka Beach 16.–20. 8., Meltemi 20.–24. 8.). Nočná zastávka v Astrose a kemp
pri Monemvasii z plánu vypadli – ani jeden sa nedá rezervovať, resp. neexistuje.

Zdrojová verzia plánu je v privátnom repozitári; tento repo obsahuje len mapu,
aby sa dala otvoriť na telefóne bez GitHub účtu. Stránky sú `noindex`.
